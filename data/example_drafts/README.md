# Example drafts

Six stand-in drafts so the notebook runs immediately after cloning.

These are **not** real submissions. Each is the title and abstract of an
already-published paper, taken from [OpenAlex](https://openalex.org/) (CC0
public bibliographic metadata) and saved as a plain text file. They stand in
for the unpublished drafts RIGAD is actually meant for.

The subfolder names show how institutions are supplied: a subfolder directly
under the drafts folder is read as the institution of everything inside it,
which lets RIGAD require working groups to cross institutional lines. A flat
folder works too — grouping then balances topics only.

Replace this folder with your own drafts, or point `DRAFTS_FOLDER` elsewhere.
